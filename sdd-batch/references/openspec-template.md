## 0. 目录约定

> **先把目录建好再填内容**。下面是项目里一份 OpenSpec 在仓库中的标准位置。

```
docs/openspec/batches/<batch-id>/
├── spec.md        ← 本文件
├── tasks.md       ← §9 任务清单可拆出
├── evidence/      ← 提前建空目录，按需往里塞证据
│   ├── README.md  ← 列出本批所有证据文件 + 类型 + 收集时间
│   ├── tests/     ← 测试报告（按类型分目录）
│   ├── screenshots/  ← 手工验证截图
│   ├── perf/      ← 压测报告
│   └── samples/   ← 接口响应样例 / 抽样对账
└── notes.md       ← 过程中的非正式记录（可空）
```

**为什么先建空目录**：
- 验收人/CI/同事用 glob 找 `batches/*/evidence/*` 不会断
- 不用边做边问"这批的 evidence 该放哪"
- 防止路径不一致导致引用断裂
